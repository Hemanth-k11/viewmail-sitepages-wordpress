Requires at least: 6.4
Tested up to: 7.1
Requires PHP: 7.4
License: GPLv2 or later

Child theme of Hello Elementor for viewmail.sitepages.in.

== How it is built ==

* Theme: Hello Elementor (parent) + this child theme
* Page builder: Elementor (free)
* Header and footer: Elementor Header & Footer Builder (free)
* Pages: Home, Services and Gallery, fully made of Elementor sections and widgets
* SEO: each page has an "SEO" box (title, description, keywords) under the editor.
  The Services page also outputs Open Graph, Twitter cards and JSON-LD schema
  (Organization, Service list, FAQPage, Breadcrumb). Skipped when Rank Math,
  Yoast or All in One SEO is active.
* Viewmail widgets (Elementor panel > "Viewmail"):
  Ad Preview Studio, Bidding Calculator, Web App Demo Explorer
* Floating WhatsApp button: Appearance > Customize > Viewmail

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose viewmail.zip,
   click Install Now. WordPress also installs Hello Elementor (the parent theme).
2. Click Activate.
3. Open Appearance > Viewmail Setup and click "Install plugins and build the site".

That installs Elementor and Elementor Header & Footer Builder, adds the
pictures to the Media Library, and creates the Home and Gallery pages,
the main menu, the header and the footer.

== Editing ==

* Pages: Pages > Home > Edit with Elementor.
* Header and footer: Appearance > Elementor Header & Footer Builder.
* Menu items: Appearance > Menus (Main Menu).
* Prices, texts, phone numbers and pictures: click them in Elementor.
